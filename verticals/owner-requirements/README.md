# Owner Requirements reference assurance contract

This directory exposes the public interface boundary for owner/project requirement assurance.

The reference contract connects authoritative obligations, Project World and evidence to governed determinations and candidate work. It does **not** include private requirement-compilation, applicability-resolution, ranking or customer-specific intelligence.

Conceptually:

~~~text
Obligation
→ applicability / population
→ evidence
→ determination
→ candidate work
~~~

Missing evidence remains missing evidence; it is not automatically a failure.
