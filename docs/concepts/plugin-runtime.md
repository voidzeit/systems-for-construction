# Plugin Runtime Contract

SFC plugins add governed capabilities over shared contracts. Public manifests declare identity, family, domain, capabilities, permissions, side effects, autonomy ceiling and evidence/acceptance boundaries.

Families:

~~~text
connector
domain_pack
assurance
production
generative
intelligence
~~~

The open manifest tells an SFC-compatible runtime what a capability is allowed to do. It does not disclose production heuristics, learned ranking, customer mappings or economic routing policy.

**Open contract. Private advantage.**
