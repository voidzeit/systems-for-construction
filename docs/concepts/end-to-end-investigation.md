# End-to-end investigation

The `investigate` command demonstrates the complete local path:

```text
IFC/JSON → Project World → requirement compiler → bounded agent tools
→ candidate finding → evidence admission → proof → assurance → canonical run
```

The reference provider is deterministic so the demo is repeatable without a
network or API key. It exercises the same multi-turn runtime and tool registry
used by an HTTP provider. Replace the provider at the application boundary for
model-backed investigations; the publication boundary remains deterministic.
